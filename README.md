# joaovictoralves.tech

My personal portfolio website, self-hosted end-to-end on a Raspberry Pi 5.

🔗 **[joaovictoralves.tech](https://joaovictoralves.tech)**

## Tech Stack

**Frontend:** Angular, Tailwind CSS  
**Infrastructure:** Docker, Nginx, Raspberry Pi 5, Cloudflare Tunnel

## Architecture

The app runs as a Docker container serving a compiled Angular build via Nginx.
Traffic is routed through a Cloudflare Tunnel.
Everything runs on a Raspberry Pi 5 at home.

## Features

- Responsive design with mobile-first layout
- Self-hosted with zero cloud dependency
- Served over HTTPS via Cloudflare
